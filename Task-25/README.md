# Employee Data Validation Using Excel

## Project Overview
This project demonstrates employee data validation using Microsoft Excel to improve data accuracy and consistency.

## Objective
To reduce invalid data entries and create a more reliable employee data-entry template.

## Tools Used
- Microsoft Excel
- Data Validation
- Dropdown Lists
- Excel Formulas

## Key Features
- Dropdown lists for categorical employee fields
- Validation for employee ratings
- Date validation
- Custom error alerts
- Testing of valid and invalid entries

## Validation Rules
- Employee status and employee type dropdowns
- Business unit and pay zone dropdowns
- Gender and marital status dropdowns
- Performance score dropdown
- Employee rating restricted to values from 1 to 5
- Date-entry restrictions

## Learning Outcomes
- Learned to configure dropdown lists in Excel
- Practiced numeric and date validation
- Used error alerts to help prevent invalid entries
- Understood the importance of data quality

## Dataset
Employee dataset used for learning and demonstration purposes.
