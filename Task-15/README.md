# Task 15: Product Count Analysis

## Project Overview
This project analyzes product counts across different categories using the Sample Superstore dataset in Microsoft Excel.

## Objective
- Count products by category.
- Identify the category with the highest unique product count.
- Understand the difference between unique products and total records.

## Tools Used
- Microsoft Excel
- COUNTIF
- UNIQUE and FILTER
- Data Analysis
- Data Visualization

## Analysis Performed
- Created a category-wise product count table.
- Calculated unique Product IDs.
- Calculated total records for each category.
- Identified the category with the highest product count.

## Key Findings
- Furniture: 375 unique Product IDs
- Office Supplies: 1,083 unique Product IDs
- Technology: 404 unique Product IDs

Top Category: Office Supplies

## Conclusion
This analysis demonstrates how Excel formulas can be used to count unique products, compare categories, and generate useful business insights.
