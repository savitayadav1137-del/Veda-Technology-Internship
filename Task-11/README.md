# Task 11: Basic Data Sorting & Filtering

## Objective
To practice basic data exploration using sorting and filtering in Excel.

## Tools Used
- Microsoft Excel

## Work Completed
- Sorted sales data from largest to smallest.
- Applied filters to Category and Region.
- Used multiple filters to explore specific records.
- Identified records with negative profit.
- Answered five business questions using sorting and filtering.

## Key Learnings
- How to sort data in ascending and descending order.
- How to apply single and multiple filters.
- How to identify loss-making transactions.
- How to explore data for business insights.
