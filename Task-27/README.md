# Task 27: Date Cleaning Basics

## Objective
To standardize date formats and handle invalid dates using Python Pandas.

## Tools Used
- Python
- Pandas
- Google Colab

## Dataset
Retail Sales Dataset

## Tasks Completed
- Loaded the retail sales dataset using Pandas.
- Checked the date column and its data type.
- Converted the date column into datetime format.
- Identified invalid or missing dates.
- Created an issue log for invalid dates.
- Saved the cleaned dataset and issue log as CSV files.

## Files
- `cleaned_retail_sales.csv` — Cleaned dataset
- `date_issue_log.csv` — Issue log for invalid dates

## Key Learning
Learned how to convert date columns into datetime format, detect invalid dates using `errors='coerce'`, and create an issue log using Pandas.
