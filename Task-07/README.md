# World Happiness Report 2015 – Data Story

## 📊 Project Overview

This project analyzes the World Happiness Report 2015 dataset using Microsoft Excel.

The objective is to turn raw data into meaningful visual insights using basic charts and a simple dashboard.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Bar Chart
- Line Chart
- Pie Chart
- Data Visualization

## 📈 Charts Created

### 1. Top 10 Happiest Countries
A bar chart showing the happiness scores of the top 10 countries.

### 2. Happiness Score vs Rank
A line chart showing how happiness scores change across the top 20 happiness ranks.

### 3. Country Distribution by Region
A pie chart showing how countries are distributed across major regions.

### 4. Average Happiness Score by Region
A bar chart comparing the average happiness score across different regions.

## 🔍 Key Insights

- Switzerland has the highest happiness score among the top-ranked countries.
- Happiness scores generally decrease as the rank moves downward.
- Sub-Saharan Africa represents the largest group of countries in the dataset.
- Australia and New Zealand has the highest average happiness score among the regions.

## 📁 Project Structure

- `2015.csv` – Original dataset
- `World_Happiness_Report_2015.xlsx` – Excel analysis and dashboard
- `Dashboard.png` – Final dashboard image

## 🎯 Conclusion

The dashboard transforms the World Happiness Report 2015 dataset into a simple visual story, making country rankings, regional distribution, and happiness patterns easier to understand.
