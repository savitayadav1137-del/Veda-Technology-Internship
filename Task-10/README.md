# Simple KPI Tracking Dashboard

## Project Overview
This project was completed as part of the Veda Technology Data Analytics Internship, Level 1 – Day 10.

The objective was to create an Excel-based KPI tracking sheet that converts raw sales data into meaningful business insights.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset

Learned how to clean numeric data, calculate sales KPIs, summarize product performance, and build a formula-driven dashboard.
