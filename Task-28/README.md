# Task 28: Simple Percentage Analysis

## 📌 Project Overview
This project focuses on calculating percentage contributions by category using the Sample Superstore dataset in Microsoft Excel.

The objective is to understand how each product category contributes to total sales and present the results through a percentage table and pie chart.

## 🎯 Objectives
- Calculate total sales for each category.
- Calculate percentage contribution by category.
- Create a percentage analysis table.
- Visualize sales contribution using a pie chart.
- Verify that the total percentage equals 100%.

## 🛠️ Tools Used
- Microsoft Excel
- Sample Superstore Dataset

## 📂 Dataset
The Sample Superstore dataset contains sales and product category information.

**Key columns used:**
- `Category`
- `Sales`

## 📊 Analysis Performed
1. Calculated category-wise total sales using the `SUMIF` function.
2. Calculated grand total sales using the `SUM` function.
3. Calculated percentage contribution using the formula:

   `Contribution % = (Category Sales / Total Sales) × 100`

4. Created a percentage table.
5. Created a pie chart to visualize the contribution of each category.
6. Verified that the total contribution equals 100%.

## 🔍 Key Insights
- Technology contributed the highest percentage of total sales.
- Furniture contributed the second-highest percentage.
- Office Supplies contributed the lowest percentage.
- The total percentage contribution of all categories equals 100%.

## 📈 Deliverables
- Excel percentage analysis table
- Pie chart showing sales contribution by category
- Excel workbook containing formulas and analysis

## 💡 Learning Outcomes
- Understanding percentage contribution in business reporting.
- Using Excel formulas for sales analysis.
- Creating charts for data visualization.
- Presenting business insights clearly.
