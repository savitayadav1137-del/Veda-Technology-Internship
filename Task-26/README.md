# Task 26: Text Cleaning Basics Using Python

## Project Overview
This project focuses on cleaning and standardizing text data using Python and Pandas.

## Objectives
- Remove extra spaces.
- Standardize text formatting.
- Convert names to proper case where applicable.
- Convert email addresses to lowercase where applicable.
- Compare original and cleaned data.

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- VS Code

## Project Files
- `task26.ipynb` — Python notebook
- `cleaned_customer_data.csv` — cleaned dataset
- `before_after_comparison.csv` — before-and-after comparison

## Key Learning
Learned basic text cleaning, whitespace removal, text standardization, and CSV export using Pandas.
