# Descriptive Statistics Primer

## Project Overview
This project was completed as part of the Veda Technology Data Analytics Internship, Level 1 – Day 9.

## Objective
To calculate and interpret descriptive statistics for numerical features in the Iris dataset.

## Dataset
The Iris dataset contains four numerical features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

It also includes a categorical feature called Species.

## Tools Used
- Microsoft Excel

## Statistics Calculated
- Mean
- Median
- Mode
- Standard Deviation
- 25th, 50th, and 75th Percentiles
- Interquartile Range (IQR)

## Key Findings
- Petal length has the highest standard deviation among the four numerical features.
- Sepal width has the lowest standard deviation.
- Comparing the mean and median helps identify possible skewness.
- IQR helps explain the spread of the middle 50% of observations.

## Conclusion
This project demonstrates how descriptive statistics can summarize the central tendency, variability, and distribution of numerical data using Microsoft Excel.
