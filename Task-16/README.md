# Task 16: Simple Profit Analysis

## Objective
Compare total profit across product categories
using the Sample Superstore dataset.

## Tools Used
- Microsoft Excel
- SUMIF
- AVERAGEIF
- Data Analysis
- Data Visualization

## Analysis Performed
- Calculated total sales by category.
- Calculated total profit by category.
- Compared average profit across categories.
- Created a profit comparison chart.

## Key Findings
- Technology generated the highest total profit.
- Office Supplies generated the second-highest total profit.
- Furniture generated the lowest total profit.

## Conclusion
This analysis helps understand category-wise
profitability and the difference between sales
and profit.
