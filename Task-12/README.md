# Task 12: Missing Value Identification

## Internship
Veda Technology – Data Analytics Track

## Objective
To identify missing values in a dataset and summarize their occurrence across columns.

## Dataset
Iris Dataset

- Total Rows: 150
- Total Columns: 5

## Tools Used
- Microsoft Excel
- CSV Dataset

## Work Performed
- Checked missing values in each column using Excel's COUNTBLANK function.
- Calculated missing-value percentages.
- Created a Missing Value Summary table.
- Documented the findings and conclusion.

## Results
No missing values were found in any of the five columns.

| Column | Total Rows | Missing Values | Missing Percentage |
|---|---:|---:|---:|
| sepal_length | 150 | 0 | 0% |
| sepal_width | 150 | 0 | 0% |
| petal_length | 150 | 0 | 0% |
| petal_width | 150 | 0 | 0% |
| species | 150 | 0 | 0% |

## Conclusion
The Iris dataset contains no missing values and is ready for further data analysis. No imputation or deletion was required.

## Deliverable
Excel workbook containing the missing-value summary and findings.
