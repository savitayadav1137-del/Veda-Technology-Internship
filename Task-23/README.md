# Task 23: SQL Aggregation Basics

## Overview
This project is part of my Data Analytics learning journey with Veda Technology.

The objective of this task is to practice SQL aggregate functions using the Northwind categories dataset in MySQL Workbench.

## Dataset
- **Dataset:** Categories CSV
- **Table:** categories
- **Database:** task22_db
- **Tool:** MySQL Workbench

The dataset contains category IDs, category names, and descriptions.

## SQL Concepts Practiced
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- DISTINCT
- GROUP BY
- NULL handling

## Tasks Completed
- Counted total category records.
- Counted distinct category IDs.
- Calculated the sum and average of category IDs.
- Found minimum and maximum values.
- Grouped records by category name.
- Calculated description lengths.
- Checked NULL values in the dataset.

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## Deliverables
- SQL query script
- Screenshots of query results

## Learning Outcome
Strengthened my understanding of SQL aggregate functions and learned how to summarize and analyze structured data.
