# Task 21: Basic SQL SELECT

## Overview
This project is part of my Data Analytics learning journey with Veda Technology.

The objective is to practice fundamental SQL queries using the Chinook SQLite database.

## Dataset
- **Dataset:** Chinook SQLite Database
- **Database type:** SQLite
- **Domain:** Music Store

The database contains information about artists, albums, tracks, customers, invoices, and genres.

## SQL Concepts Practiced
- SELECT statements
- WHERE conditions
- ORDER BY (ASC and DESC)
- AND operator
- BETWEEN operator
- IS NOT NULL
- LIMIT clause
- COUNT() aggregate function

## Tasks Completed
1. Retrieved records from database tables.
2. Selected specific columns.
3. Filtered tracks by price and duration.
4. Retrieved customers by country.
5. Sorted invoices and tracks.
6. Used BETWEEN and IS NOT NULL conditions.
7. Counted the total number of tracks.

## Tools Used
- SQLite
- DB Browser for SQLite
- GitHub

## Deliverables
- SQL query file
- Screenshots of query outputs

## Learning Outcome
Improved my understanding of SQL fundamentals and learned how to retrieve, filter, and sort structured data using SQLite.
