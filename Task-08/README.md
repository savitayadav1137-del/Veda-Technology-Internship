# Task 8 – Sales Tracker

## 📌 Project Overview

This project focuses on creating a Sales Tracker using Google Sheets.
The tracker organizes retail sales data and provides daily, weekly, and
monthly sales summaries.

## 🛠️ Tool Used

- Google Sheets

## 📊 Dataset

The project uses a retail sales dataset containing transaction,
customer, product, quantity, price, and total amount information.

## 🔹 Features

- Raw sales data management
- Daily sales tracking
- Weekly sales tracking
- Monthly sales tracking
- Total revenue calculation
- Total quantity calculation
- Data validation
- Manual verification of totals
- Professional spreadsheet formatting

## 📈 Key Results

- Total Revenue: ₹456,000
- Total Quantity Sold: 2,514
- Total Transactions: 1,000

## ✅ Verification

The calculated totals were checked against manual values and verified.

## 📚 Learning Outcome

Through this task, I learned how to organize sales data,
use spreadsheet formulas, apply data validation, and create
automated sales summaries using Google Sheets.
