# Task 24: Excel PivotTable Basics

## Project Overview
This project focuses on analyzing the Sample Superstore dataset using Microsoft Excel PivotTables to create quick and meaningful sales summaries.

## Objectives
- Analyze total sales by product category.
- Compare sales across different regions.
- Analyze monthly sales trends.

## Tools Used
- Microsoft Excel
- PivotTables
- Data Summarization
- Basic Data Analysis

## Analysis Performed
1. Sales by Category
2. Sales by Region
3. Sales by Month

## Key Insights
- Technology recorded the highest sales among the three product categories.
- The West region generated the highest sales among the four regions.
- Monthly sales analysis helps identify high-performing months and sales trends.

## Deliverables
- Three Excel PivotTables
- Sales summary and insights
- Excel workbook

## Dataset
Sample Superstore dataset.

## Learning Outcomes
Learned how to create PivotTables, summarize sales data, organize row and value fields, and extract business insights using Excel.
