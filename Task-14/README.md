# Task 14: Basic Sales Summary

## Project Overview
This project focuses on creating a basic sales summary using Excel. The objective is to calculate important business KPIs and present them in a simple, professional format.

## Tools Used
- Microsoft Excel
- Excel formulas and cell formatting

## Dataset
Retail Sales Dataset containing 1,000 transactions.

## Key Performance Indicators (KPIs)
1. **Total Sales:** ₹4,56,000
2. **Average Sales:** ₹456
3. **Transaction Count:** 1,000

## Formulas Used
- Total Sales: `SUM()`
- Average Sales: `AVERAGE()`
- Transaction Count: `COUNTA()`

## Deliverables
- Sales Summary worksheet
- Three KPI cards
- Formula-based calculations
- Manual verification of results

## Learning Outcomes
- Learned to calculate basic sales KPIs.
- Practiced Excel formulas.
- Created professional KPI cards.
- Understood how business summaries support decision-making.

## Conclusion
This task helped me understand how to summarize sales data and present key business metrics using Excel.
